# Contexte UX/UI PlanetLS

- Les interfaces admin et dashboard privilegient une lecture rapide, des cartes compactes et des onglets clairs.
- Les longs blocs de texte doivent etre repliables ou contextuels.
- Les pages denses doivent etre decoupees en vues plutot qu'empilees.
- Le responsive mobile reste une attente forte, meme pour les pages de pilotage.
- L'accessibilite ne doit pas etre repousse a la fin.
